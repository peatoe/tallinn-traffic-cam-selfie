# Contributing

Thanks for wanting to help. This is a small hobby project with strong
opinions; the rules below keep it easy to maintain and legally clean.

## The one-paragraph architecture

Everything lives in `app/`: plain HTML, CSS, and JavaScript, no build step,
no framework, no bundler. Leaflet is vendored in `app/vendor/`. There is no
backend: the browser talks straight to the city's camera server and the tile
host, and everything a user creates (photos, favorites) stays in their own
browser storage. Keep it that way.

## Run it locally

```bash
python3 -m http.server 8123 --directory app
```

Open http://localhost:8123 and use the test parameters:

- `?at=59.437,24.754` fakes your location (any coordinates work; far-away
  ones trigger the outside-Tallinn greeting)
- `?cam=cam009` deep-links a camera (cam009 also shows the
  approximate-location notice)

## Ground rules

1. **No dependencies.** No npm, no CDN scripts, no analytics, no fonts or
   assets fetched from third parties at runtime. If the about page's privacy
   claims would become false, the change is wrong.
2. **Design system.** Colors come from the CSS variables in `style.css`
   (`--ink`, `--paper`, `--accent`, `--mist`, `--line`); do not introduce new
   colors. Type is Aino / Aino Headline, headlines lowercase.
3. **UI copy** is lowercase, uses periods rather than dashes, and contains no
   emojis. Safety wording (photograph yourself, obey traffic laws, no
   trespassing) must not be weakened.
4. **Icons** come from the Brand Estonia set
   (https://toolbox.estonia.ee/document/17), inlined as `<symbol>`s in
   `index.html` with `stroke="currentColor"` and the decorative outer circle
   removed. When you add one, credit it in both `THIRD-PARTY-NOTICES.md`
   files.
5. **iOS is a first-class target.** Test on an iPhone (or at minimum Safari)
   before opening a PR. Hard-won rules: no SVG `url()` filters on Leaflet
   panes (Safari drops them; the map recolor happens on canvas instead),
   `navigator.share`/clipboard need HTTPS, and the app must behave in
   standalone (Add to Home Screen) mode.
6. **Be gentle with the camera server.** The list view loads through a
   bounded queue and refreshes only what is on screen. Do not add polling or
   bulk fetching beyond it.

## Data pipeline

`app/data/cameras.json` is generated by `python3 scripts/update-cameras.py`
(Overpass + Maa-amet geocoding, cached in `.cache/`). Hand-edit coordinates
only for cameras marked `"approx": true`, and prefer fixing the generator.

## Pull requests

- Keep commits small with lowercase, present-tense messages
  ("add favorites sorting").
- UI changes: include a before/after screenshot, and check both the 375 px
  phone width and a desktop width.
- If you touched licensing-relevant things (assets, data, embedded works),
  update `THIRD-PARTY-NOTICES.md`, `app/THIRD-PARTY-NOTICES.txt`, and the
  in-app about page together.
